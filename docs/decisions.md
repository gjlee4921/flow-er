# Decisions

| Decision | Reason |
| --- | --- |
| Per-gate U-Net (UNITO-style) as the main model | Reproduces 2D expert gates as editable polygons; trains on CPU from ~10 gated samples |
| Splits by mouse/donor (and date), never by cell | Cells from the same animal in train and test inflate scores |
| Data and trained models kept outside git | Size, and donor data must never be published |
| Package name `flow_er` | `flower` is an existing PyPI package (Celery's monitor) |
| Every change the agent makes is a draft until kept | Nothing in an analysis changes without the scientist seeing it; undo is always one click |
| The agent never places gates or produces numbers | Gates come from FlowJo, the scientist or the models; numbers come from saved tables, so every figure traces to a file |
| Figures are specs over saved tables, drawn by the browser | A new way of showing a result can be asked for in a sentence without running generated code, and stays interactive |
| The web app's agent runs on OpenAI's Responses API with `store=False` | Function tools with reasoning models need it; nothing is kept on OpenAI's side. The adapter is one function, so Claude can replace it |
| The data lab has its own assistant, apart from the main chat | Looking and laying out is a different job from planning: a separate thread keeps both short, and lab-only tools mean it can never change the analysis |
| Response baseline = the well named in meta `unstim_source`, same method and gate; no response when that well's prediction is missing | Exact donor pairing from the cache; never mixes methods |
| Frequencies and errors are computed on the cached parent cells (the 200k subsample when a parent is larger); precision/recall are NaN when their denominator is 0 | Same cells the models are scored on; ALS keeps every cell |
| U-Net input normalisation: log1p(count) / max of the image, per channel (density and unstim alike); template stays 0/1; no ImageNet mean/std for the pretrained encoder | Spec only says "count image"; scale-free across event counts; one rule for every model, stored in each recipe |
| Shared-model channels: [density, template, unstim] with unstim = zeros for non-cytokine gates; the `_1ch` variant drops unstim ([density, template]) | One fixed input layout for every gate; the variant isolates what the unstimulated well adds |
| Augmentation (shared model, training only): per-axis shift ±5 px and scaling ±10% about the centre, nearest-pixel, same map for density, unstim and mask (density/unstim zero-filled, mask edge-replicated); event re-subsampling = binomial thinning of the counts with keep p ~ U(0.5, 1) | Equivalent in distribution to subsampling cells, without reading cell_bins every step; mask keeps gates that run to the plot edge |
| Pretraining weights datasets equally per epoch (sampling with replacement, 1/files-of-dataset); early stopping and grid selection use the mean per-image Dice of sigmoid > 0.5 (1 when both masks are empty) | split_v1 pretrain note; Dice per image as in UNITO's selection |
| Polygon = largest closed 0.5 contour of the probability map padded with zeros, simplified with a 0.5-pixel tolerance | Edge-touching gates still close; fewer vertices to edit |
| Labels = FlowKit per-cell memberships; FlowJo's saved counts are the noise floor beside every number | A time-boxed biex investigation could not make FlowKit reproduce FlowJo (ALS IL-4/IL-17, spectral #4/#5) |
| Shared display transform for every dataset: linear x / $PnR for scatter, logicle (T = $PnR, W = 0.5, M = 4.5, A = 0) for fluorescence; pixel = round(100 v) | Workspaces use different biex settings; one transform makes images comparable; masks map pixel centres back into each workspace's display space |
| Every method is scored gate by gate on the expert parent cells (no cascade) | Isolates each gate; cascading is a later product step |
| ALS template = donor 2008's unstimulated well (first training donor); other datasets = their first training sample | Simplest fixed reference, always on the training side |
| Classical peak-shift uses the cached 101x101 parent density, two 3x3 box-smoothing passes, window = template bounding box + 50% per side; < 120 parent cells keep the template | The prototype's peak2d on the shared image grid |
| Classical cytokine threshold: shift the template along x until the donor's unstimulated well has the background rate = median expert positive fraction of the training (train + finetune) donors' unstimulated wells; bisection within ±0.4 display units; same shift for the donor's three wells | How experts set ICS thresholds; one rate per gate fitted on training donors only |
| UNITO per gate and the fine-tuned shared model train on the ALS train + finetune donors (8), early stopping on the 2 val donors | Spec rows 3/5 say "benchmark training individuals"; the finetune role adds screen-4 donors to training |
| Step-4 UNITO budget: grid points capped at 1.5 min (max 40 epochs, patience 8) on 12 CPU threads | The spec's 31 M-parameter U-Net takes ~1.5 s per batch of 8 on CPU; uncapped the grid would exceed the 1-1.5 h limit |
| Shared-model pretraining uses only gates whose FlowKit counts agree with FlowJo (registry `agrees_with_flowjo`) and no Time gates | split_v1 pretrain rule; disagreeing gates would teach the wrong boundary |
| Cache build reads events through a memory map and gates them 50k at a time with the workspace's FlowKit gating strategy; files over 500k events keep a fixed random 500k-event subsample (seed 0) | FlowKit's full load needs ~3.6 KB/event (~14 GB for the largest spleen file); per-event gating makes chunks exact (checked: identical labels, values, images and masks on an ALS well) |
| Runtime membership = the returned polygon (point-in-polygon in display space), not the probability map's pixels | Counts, the drawn polygon, user edits and the GatingML export then agree exactly (checked: 0 cells differ on 15 ALS gates); pixels and polygon differ by < 1% of cells. Evaluation still scores pixel lookups |
| Templates are polygons in display units, whatever their source; a FlowJo gate is rasterised exactly (gate_mask) and traced back | One format for .wsp, saved templates and accepted gates; any FlowJo gate type works |
| GatingML export: raw (compensated) units, edges densified to 0.005 display units before conversion, spillover written as the "spill" matrix, gate ids made XML-safe (`[^A-Za-z0-9._-]` -> `_`, duplicates get `__<parent>`) | Raw units as asked; display-straight edges are curved in raw units; GatingML ids are xs:ID |
| Boundary confidence = mean `|2p - 1|` of parent cells within 2 px of the 0.5 contour; flag below 0.6 | Cheap, per gate, and high only when the model is decisive where it matters |
| Lab fine-tuning holds out individuals by hash (~20%), so a held-out individual stays held out as labels accumulate; promotion needs a lower held-out mean error and no gate worse by > 1 pp | Stable comparisons across retrains; no silent regressions on single gates |
| A model version only becomes current when promoted (or by set_current); register_version never auto-promotes | A failed first retrain must not replace template copy / the base model |
| Non-ALS templates come from the first sample of the evaluation's own training stage (same dataset and workspace) that has the gate | Workspaces have different gate trees; another evaluation's training mice can be this one's test mice (MO280 rounds 1/2) |
| A gate polygon that reaches the plot edge is extended past it: vertices on or beyond the border move to -0.5 / 1.5 display units (prob_to_polygon, template copy, user edits) | The edge pixels hold every event beyond the axis (pixel = round(100 v) clipped); clipping the polygon at the axis dropped those events from the gate, e.g. ALS CD8 Single Positive end to end 3.35 -> 0.43 pp mean error on the 6 test donors (the evaluation, scored on pixels, gave 0.52) |
| Runtime routing: per-gate UNITO where the lab has a model for that gate, otherwise template copy (flagged for review); no shared U-Net, no CytoBERT | Locked ALS test and MO280 (models.md section 1): UNITO is the most consistent; the shared model and CytoBERT add no measurable gain and add failure modes |
| Public dataset group IDs (e.g. the ALS donors' 4-digit IDs from Zenodo) may appear in split definitions and tests | They are already public and the split must be reproducible from the repo; donor-level data (FCS files, per-donor results) still never goes in git |
| The data lab draws every file in the models' display (linear x / $PnR, logicle T = $PnR W 0.5 M 4.5) whenever the files' FlowJo workspaces disagree or use biex; FlowJo's shapes are moved into it (edges split first; a side at the end of FlowJo's scale stays open) | Lab gates are shared by every file. ALS and HC workspaces scale FITC differently (biex top 3.2 vs 4.1 decades) and biex runs to about 4096, so one gate meant different cells per file (HC "IFNy (model)" read 80–93% of CD4). In one display every FlowJo gate still holds FlowJo's cells (all 12 ALS files, within 2%) and model polygons need no conversion |
| A model gate put up for review remembers the file it was reviewed on (`reviewed_on`); teaching a file counts only that file's reviewed gates as the scientist's; a second reviewed file gets "(model 2)" | Kept lab gates are project-wide; without this, teaching file B counted file A's corrections as B's |
